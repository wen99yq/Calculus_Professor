# Calculus_Professor 使用说明

> 你好，我是你的**微积分助教**。
> 我不是来给你答案的，我是来让你**不用再问答案**的。
> 这份说明不长，花 3 分钟看完，后面就能顺畅用了。

> 📦 **还没安装？** 装法见 [`docs/安装与转移指南.md`](docs/安装与转移指南.md)。
> 本仓库是 **WorkBuddy** 的 skill；装好后需重启 WorkBuddy 才会生效。

---

## 一、我是什么

一个装在 WorkBuddy 里的微积分助教。教材对齐 **苏德矿《微积分》第三版（高等教育出版社）**，目前覆盖**上册六章**：

1. 函数与极限
2. 导数与微分
3. 微分中值定理及导数的应用
4. 不定积分
5. 定积分及其应用
6. 常微分方程

（下册的级数、多元微积分等，之后可以扩展进来。）

---

## 二、怎么开始

**直接说话就行，不用记命令。**

第一次跟我说话时，我会先问你三个问题：

- 你中学数学的底子怎么样？
- 这学期目标是补考过关、期末达标，还是考研提高？
- 用的哪本教材、现在讲到第几章了？

答完之后，我会建一份学习档案，之后每次讲解和出题的难度都会按你的实际水平来。

---

## 三、我能帮你做什么

| 你想做的事 | 直接这样说 |
|---|---|
| 搞懂一个概念 | "导数到底是什么？" / "为什么极限要这么定义" |
| 做一道题（我会先引导你） | 把题目贴给我，或说"这题怎么做" |
| 查自己错在哪 | "我这么算为什么错了"（把草稿一起发来） |
| 要练习 | "出 3 道极限的题" / "考考我" |
| 总结套路 | "分部积分有几种套路" |
| 整理笔记 | "把刚才那个整理成笔记" |
| 看章节脉络 | "第一章讲了什么" |
| 安排复习 | "我该怎么复习" |
| 看学习报告 | "给我一份报告" |

## 四、关于"我不直接给答案"

这是刻意的设计，不是抠门：

- **你做作业原题时**，我会先问"你自己想到哪一步了"，然后给你**思路和关键步骤**，但**不写完整最终答案**——那份答案交上去，老师一眼就知道过程不是你的。
- **你自己练习时**，我会先引导你 2~3 轮；如果你说"不会"或者"直接讲吧"，我**立刻**从头讲到尾，绝不把你晾在那儿。
- 我永远**一次只问一个问题**，不会一口气丢三个问号给你。

想直接听讲解，随时说一句 **"直接讲"** 就行。

## 五、你的档案存在哪

在**你当前工作目录**下的 `微积分学习/` 文件夹里：

```
微积分学习/
├── 学生档案.md      你的水平、目标、薄弱环节
├── 错题本.md        做错的题 + 错因分类 + 正确思路
├── 学习计划.md      哪天做哪几题
├── 进度追踪.md      各章掌握度、练习记录
├── 笔记/
│   ├── 知识卡片/    一个知识点一张卡
│   └── 知识地图/    每章的脉络与公式体系
└── 报告/            生成的 HTML 学习报告
```

这个文件夹是**你的**，可以随时打开看、备份、带走。我不会写死在任何固定的系统路径上。

## 六、和 Obsidian 联动

如果你电脑上装了 Obsidian，我整理的**知识卡片会自动写成 Obsidian 格式**：
带标签、带 `[[双向链接]]`，卡片之间自动串联，用久了就长出一张自己的微积分知识图谱。

**第一次写笔记前我会问你一句**："我找到你的库在 `X`，微积分笔记写到 `X\微积分\` 可以吗？"
——因为自动找到的只是"你最近打开过的库"，万一那是你的日记库或者别的科目库，我得先确认。

你也可以直接告诉我："我的 Obsidian 库在 `D:\我的笔记`"，我就记下来，以后不用再说。

**没装 Obsidian 也没关系**——笔记一样会存在 `微积分学习/笔记/` 里，只是少了双链的便利。

## 七、我会"验算"，而且会当面算给你看

我手算积分也可能出错，所以关键结果我会用**符号计算工具**再核对一遍。核对的时候我会把过程给你看：

> 这个结果我用符号计算工具核对一下——

**这是故意的**：让你知道有这么一个自查手段。以后你自己算完不定积分，也可以对结果求个导，看能不能还原回被积函数——这是最朴素也最有效的自检。

（如果某次环境里没有这个工具，我会**直接告诉你"这次没做机器验算"**，不会假装算过。）

## 八、常见问题

**Q：公式显示成乱码了怎么办？**
A：跟我说"公式显示不出来"，我会切换成纯文本写法，整段重新发给你。

**Q：我说"笔记没进 Obsidian"？**
A：告诉我你的库路径，或者就说"笔记放本地就行"。也可以让我检查一下：我会运行一次库探测。

**Q：我想换个难度。**
A：说"微积分 切换档位 基础补强"（或 期末达标 / 考研提高）。我也会在发现你明显跟不上或太轻松时主动提出来。

**Q：我想让它出下册的题。**
A：目前知识库只覆盖上册六章。下册问题我仍然可以回答，但会标注"未经过本知识库校订"。

**Q：学习报告是什么？**
A：一份 HTML 文件，里面有你的进度、错题分布图、薄弱环节和下一步建议，可以打印出来贴在书桌前。说"给我一份报告"就有了。

## 十、一句真心话

微积分不难在计算，难在"为什么要这么算"。
你算错的时候我不会先说"错了"——我会先找你在哪一步是**对的**，再看那一步之后发生了什么。

慢一点没关系，我们一步一步来。
