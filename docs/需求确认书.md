## 三、教材锚点与章节体系

**锚点教材**：苏德矿、吴明华、童雯雯 主编《微积分》第三版，高等教育出版社 2021
（上册 ISBN 9787040548167，下册 ISBN 9787040553949）

### 一期覆盖：上册 6 章

| 章 | 章名 |
|---|---|
| 第1章 | 函数与极限 |
| 第2章 | 导数与微分 |
| 第3章 | 微分中值定理及导数的应用 |
| 第4章 | 不定积分 |
| 第5章 | 定积分及其应用 |
| 第6章 | 常微分方程 |

> 注：教材第三章含「导数在经济中的应用」（边际分析、弹性分析），经管类学生仍会用；助教讲解时保留经济背景例题。

### 二期扩展（架构预留，本期不实施）

下册 6 章：级数 / 空间解析几何与矢量代数 / 多元函数微积分 / 重积分 / 曲线积分与曲面积分 / 含参量积分

**扩展方式**：采用「章节注册表」结构——新增章节只需在注册表中登记并补一份知识速查文档，主流程与路由逻辑无需改动。

## 四、十种工作模式

| 模式 | 触发场景 | 优先级 |
|---|---|---|
| ① 摸底建档 | 首次使用；学生主动说"重新摸底" | 首次强制 |
| ② 概念讲解 | "极限是什么""为什么导数这么定义" | 常驻 |
| ③ 习题引导 | 贴题求解（默认走引导） | 常驻 |
| ④ 错因诊断 | "我这么算为什么错" | 常驻 |
| ⑤ 出题练习 | "出几道题练练""考考我" | 常驻 |
| ⑥ 套路总结 | "分部积分有几种套路" | 常驻 |
| ⑦ 笔记整理 | 沉淀知识卡片 → Obsidian | 常驻 |
| ⑧ 知识地图 | 章节脉络、公式体系 | 常驻 |
| ⑨ 学习计划 | 薄弱点 → 本周安排 | 常驻 |
| ⑩ 学习报告 | 生成 HTML 诊断报告 | 按需 + 章末提醒 |

**路由规则**：默认由助教自动识别意图；学生输入中文口令（如「微积分 报告」）可强制指定模式。

## 六、Obsidian 集成方案（自包含）

1. **Vault 自动探测**（跨平台读取）
   - Windows：`%APPDATA%\obsidian\obsidian.json`
   - macOS：`~/Library/Application Support/obsidian/obsidian.json`
   - Linux：`~/.config/obsidian/obsidian.json`
   - 取 `"open": true` 的 vault 条目
2. **回退策略**：探测失败 → 笔记写入 `微积分学习/笔记/` 并提示学生手动指定 vault 路径
3. **笔记格式**：Obsidian 原生 Markdown
   - YAML frontmatter：`tags`、`chapter`、`knowledge_point`、`mastery`
   - 正文使用 `[[双向链接]]` 建立知识卡片互链，`#微积分/第1章` 形式的层级标签
4. **可选增强**：若目标机器上存在 `obsidian-cli`，则用它做搜索/移动/重命名（可自动更新双链）；不存在则纯文件读写，功能不受影响

## 七、验算能力方案（自包含）

- **技术选型**：Python + sympy（符号计算）
- **参考环境**：`~/.workbuddy/binaries/python/envs/default/`（sympy 1.14.0）
- **跨机器适配**：脚本自动探测可用的 Python + sympy 环境（含常见 venv 路径）；**探测失败则降级为纯模型推导**，并明确告知用户"本次未验算"
- **展示方式**：验算命令与结果**展示给学生**，顺带教会其自查方法
- **覆盖场景**：求导、不定积分、定积分、极限、方程求解、泰勒展开

## 九、技术约束

1. **零硬编码路径**——skill 内不得出现本机绝对路径，否则无法分享
2. **优雅降级**——Obsidian / sympy / 公式渲染 任一不可用，功能不中断
3. **公式渲染双轨**——简单式 Unicode，复杂式 LaTeX；并提供渲染失败时的纯文本兜底
4. **离线可用**——知识速查内置，不依赖联网
5. **可扩展**——章节注册表结构，便于二期加入下册
