# 安装与转移指南

> 本指南说明如何把 **Calculus_Professor** 装到一台新电脑上。
> 全文不含任何特定机器的路径，Windows / macOS / Linux 均适用。

---

## 一、这是什么

一个运行在 **WorkBuddy** 里的大学微积分助教 skill。教材锚点为
苏德矿、吴明华、童雯雯《微积分》第三版（高等教育出版社 2021），当前覆盖**上册六章**：

1. 函数与极限
2. 导数与微分
3. 微分中值定理及导数的应用
4. 不定积分
5. 定积分及其应用
6. 常微分方程

## 三、安装

### 方式 A：git clone（推荐，便于日后更新）

把仓库**直接克隆到 skill 目录**，克隆出来的文件夹名必须是 `Calculus_Professor`：

```bash
git clone https://github.com/<你的用户名>/Calculus_Professor.git \
  ~/.workbuddy/skills/Calculus_Professor
```

Windows（Git Bash / PowerShell）对应路径为
`C:\Users\<你的用户名>\.workbuddy\skills\Calculus_Professor`。

### 方式 B：下载 ZIP（无需 git）

1. 在仓库页面点 **Code → Download ZIP**。
2. 解压得到 `Calculus_Professor-main` 文件夹。
3. **重命名为 `Calculus_Professor`**（去掉 `-main`）。
4. 整个文件夹原样放进 skill 目录：

   | 系统 | 目标路径 |
   |---|---|
   | Windows | `C:\Users\<用户名>\.workbuddy\skills\Calculus_Professor\` |
   | macOS / Linux | `~/.workbuddy/skills/Calculus_Professor/` |

不要改动内部结构——`SKILL.md` 必须在文件夹根部。

### 安装后

**重启 WorkBuddy**（或新开一个会话），让它重新扫描 skill 目录。
然后打开 `README.md` 看一眼，大约 3 分钟。

## 四、依赖（除 WorkBuddy 外都不强制）

| 依赖 | 作用 | 缺失时的表现 |
|---|---|---|
| **WorkBuddy** | 运行环境 | **必需**，没有就跑不起来 |
| Python + sympy | 验算积分 / 导数 / 极限 | **可选**。找不到时自动降级：助教仍会讲解，但会**如实说明"本次未做机器验算"**，并给出人工自查方法 |
| Obsidian | 知识卡片双链 | **可选**。探测不到库时，笔记写到 `微积分学习/笔记/`，功能不中断 |

**想让验算能力生效**，装一个带 sympy 的 Python 环境即可：

```bash
python -m venv ~/.workbuddy/binaries/python/envs/default
~/.workbuddy/binaries/python/envs/default/bin/pip install sympy
```

Windows 的 `bin/` 换成 `Scripts\`，pip 可执行文件名为 `pip.exe`。
脚本也会自动搜索常见的虚拟环境位置，所以装在别处通常也能被找到。

## 五、首次使用验证清单

- [ ] **能加载**：新会话说「微积分 帮助」，能看到模式菜单
- [ ] **能摸底**：说「微积分 摸底」，助教询问基础水平与目标
- [ ] **能建档**：当前目录出现 `微积分学习/` 文件夹，含 `学生档案.md`
- [ ] **能讲解**：问「导数到底是什么」，得到直观解释（可能配图）
- [ ] **能验算**：问「∫x·eˣ dx 等于多少」，得到 `(x-1)eˣ + C` 且**附验算过程**
- [ ] **能出题**：说「微积分 出题 3道 第1章」，得到题目 + 参考答案
- [ ] **能出报告**：说「微积分 报告」，生成 `微积分学习/报告/*.html` 可双击打开
- [ ] **Obsidian 联通**：说「整理成笔记」，助教先询问 vault 路径，确认后卡片出现在 `<vault>/微积分/` 下

## 六、学习档案落在哪

助教使用**相对路径**，不写死任何机器路径：

- 默认在当前**工作目录**下创建 `微积分学习/`（学生档案 / 进度追踪 / 错题本 / 学习计划 / 笔记 / 报告）。
- 换句话说，你在哪个项目里学习，档案就落在哪里，跟着项目走。
- 想换位置，直接跟助教说即可，或手动移动整个 `微积分学习/` 文件夹。

## 七、关于 Obsidian

- skill **内置**跨平台探测能力（Windows 读 `%APPDATA%\obsidian\obsidian.json`，macOS 读
  `~/Library/Application Support/obsidian/obsidian.json`，Linux 读 `~/.config/obsidian/obsidian.json`），
  不依赖任何外部 Obsidian 插件或 skill。
- 取「最近打开」的库作为候选，但**首次写入前一定会先问一句**确认，不会偷偷往你的库里写。
- 想固定到某个库，对助教说「微积分 设置vault `<路径>`」，它会写进本目录的 `config.json`。
- `config.json` 是**本机记录**，已在 `.gitignore` 中，不会被提交，也不会随仓库分发。
- 若本机未装 Obsidian：笔记落到 `微积分学习/笔记/`，纯 Markdown，日后可直接拖进任何 vault。

## 八、扩展下册章节

一期只做了上册 6 章。要加下册（级数 / 空间解析几何与矢量代数 / 多元函数微积分 / 重积分 /
曲线积分与曲面积分 / 含参量积分）：

1. 在 `references/` 新增 `07_级数.md` … `12_含参量积分.md`
   - 格式对齐现有章节文件（七个 `##` 大节：〇知识地图 / 一逐节速查 / 二公式总表 /
     三题型套路 / 四易错点 / 五经济应用 / 六自测清单 / 七章节联系）
2. 修改 `SKILL.md` 第 1 节的「章节注册表」，把对应行状态改为 `✅ 已启用`
3. 其余（路由、档案、笔记、报告、绘图）**无需改动**
