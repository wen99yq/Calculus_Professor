## 一、逐节知识速查

### §1 不定积分的概念

- **核心定义**：
  - **原函数**：设 F'(x)=f(x) 在区间 I 上成立，则 F(x) 称为 f(x) 在 I 上的一个原函数。
  - **不定积分**：f(x) 的全体原函数称为 f(x) 的不定积分，记作
    $$\int f(x)\,dx = F(x)+C$$
    其中 F'(x)=f(x)，C 为任意常数（积分常数）。
  - **原函数存在定理**：若 f(x) 在区间 I 上连续，则 f(x) 在 I 上存在原函数（连续函数必有原函数）。

- **关键定理/公式**：
  1. $\dfrac{d}{dx}\int f(x)dx = f(x)$（求导与不定积分互逆，先积后导还原）。
  2. $\int F'(x)dx = F(x)+C$（先导后积差常数）。
  3. 线性性质：$\int [a f(x)+b g(x)]dx = a\int f(x)dx + b\int g(x)dx$（a,b 常数）。
  4. 若 F 是 f 的一个原函数，则 F+C（C 任意常数）是 f 的全体原函数。

- **典型例题**：
  **例1** 已知曲线 y=F(x) 过 (1,2) 且切线斜率 f(x)=2x，求曲线方程。
  **解**：F'(x)=2x ⇒ F(x)=∫2x dx = x² + C。代入 (1,2)：2=1+C ⇒ C=1。故 F(x)=x²+1。

  **例2** 验证 ∫2x dx = x²+C。
  **解**：d/dx(x²+C)=2x，故 x²+C 是 2x 的全体原函数，成立。

- **易错点**：
  1. 不定积分结果**必须加常数 C**，漏 C 视为错误。
  2. 原函数存在定理只保证"连续⇒有原函数"，不连续函数未必无原函数（如带可去间断的函数无原函数，但有振荡间断的 F(x)=x²sin(1/x) 导数存在且是某函数原函数）。讲解时以连续条件为主。
  3. 定积分上限函数与不定积分不同，不要混淆记号。

### §2 求不定积分的几种基本方法

#### 2.1 凑微分法（第一类换元）

- **核心定义**：
  - 若 ∫f(u)du = F(u)+C，且 u=φ(x) 可导，则
    $$\int f(\varphi(x))\varphi'(x)\,dx = \int f(u)\,du = F(\varphi(x))+C$$
    本质是把 φ'(x)dx 凑成 du，故称"凑微分"。

- **关键定理/公式**（常见凑微分形式，至少 8 组）：
  1. dx = d(x+a)（a 常数）
  2. x dx = (1/2)d(x²)
  3. x² dx = (1/3)d(x³)
  4. (1/x) dx = d(ln|x|)
  5. e^x dx = d(e^x)
  6. cos x dx = d(sin x)；sin x dx = -d(cos x)
  7. (1/(1+x²)) dx = d(arctan x)；(1/√(1-x²)) dx = d(arcsin x)
  8. (1/(2√x)) dx = d(√x)；a^x dx = (1/ln a) d(a^x)
  9. (1/cos²x) dx = d(tan x)；(1/sin²x) dx = -d(cot x)

- **典型例题**：
  **例1** 求 ∫2x·e^{x²} dx。
  **解**：令 u=x²，du=2x dx，原式=∫e^u du = e^u + C = e^{x²}+C。

  **例2** 求 ∫(ln x)/x dx。
  **解**：u=ln x，du=(1/x)dx，原式=∫u du = u²/2 + C = (ln x)²/2 + C。

- **易错点**：凑微分后**变量要还原回 x**；注意 (1/x)dx=d(ln|x|) 中 x≠0 且加绝对值。

#### 2.2 变量代换法（第二类换元）

- **核心定义**：
  - 令 x=φ(t)（φ 单调可导、φ'(t)≠0），则
    $$\int f(x)\,dx = \int f(\varphi(t))\varphi'(t)\,dt$$
    算出后再以 t=φ⁻¹(x) 代回。

- **关键定理/公式**（三角代换适用根式）：
  1. 含 √(a²-x²)：令 x=a·sin t（t∈(-π/2,π/2)），√(a²-x²)=a·cos t。
  2. 含 √(a²+x²)：令 x=a·tan t（t∈(-π/2,π/2)），√(a²+x²)=a·sec t。
  3. 含 √(x²-a²)：令 x=a·sec t（适当区间），√(x²-a²)=a·tan t。
  4. 根式代换：含 √(ax+b) 令 t=√(ax+b)（线性根式）；含 √(ax+b)、√(cx+d) 可令公共根式。
  5. 倒代换：x=1/t，常用于有理分式且分母次数高于分子较多时。
  6. 欧拉代换（√(ax²+bx+c) 情形，教材或略）。

- **典型例题**：
  **例** 求 ∫ dx/√(a²-x²)（a>0）。
  **解**：令 x=a sin t，dx=a cos t dt，√(a²-x²)=a cos t。原式=∫(a cos t)/(a cos t) dt = ∫dt = t + C = arcsin(x/a)+C。

- **易错点**：
  1. 三角代换后**回代要用直角三角形**或反三角函数正确还原，别把 t 留着。
  2. 注意 sec、tan 代换的**定义域/符号**（开方取正需限定 t 区间）。
  3. 倒代换可能引入 |t|，回代时按 x 正负处理绝对值。

#### 2.3 分部积分法

- **核心定义**：
  - 由 (uv)'=u'v+uv' 积分得
    $$\int u\,dv = uv - \int v\,du$$
    称为分部积分公式。选 u 口诀：**反对幂三指**（反三角函数、对数、幂函数、三角函数、指数函数，越靠前越优先选作 u）。

- **关键定理/公式**：
  1. 公式：∫u dv = uv - ∫v du。
  2. 选 u 优先级（作 u 的优先序）：反三角函数 > 对数函数 > 幂函数 > 三角函数 > 指数函数。

- **典型例题**：
  **例1**（幂函数×指数）求 ∫x e^x dx。
  **解**：u=x, dv=e^x dx ⇒ du=dx, v=e^x。原式=x e^x - ∫e^x dx = x e^x - e^x + C = e^x(x-1)+C。

  **例2**（对数）求 ∫ln x dx。
  **解**：u=ln x, dv=dx ⇒ du=(1/x)dx, v=x。原式=x ln x - ∫x·(1/x) dx = x ln x - x + C。

  **例3**（反三角）求 ∫arctan x dx。
  **解**：u=arctan x, dv=dx ⇒ du=dx/(1+x²), v=x。原式=x arctan x - ∫x/(1+x²) dx = x arctan x - (1/2)ln(1+x²)+C。

  **例4**（循环型）求 ∫e^x sin x dx。
  **解**：u=sin x, dv=e^x dx ⇒ 原式=e^x sin x - ∫e^x cos x dx；对 ∫e^x cos x dx 再分部：=e^x sin x - [e^x cos x + ∫e^x sin x dx]。移项 2∫e^x sin x dx = e^x(sin x - cos x) ⇒ 原式=e^x(sin x - cos x)/2 + C。

- **易错点**：
  1. 分部后 ∫v du **比原式更简单**才选对 u，否则换选。
  2. 循环型（e^x sin x、e^x cos x、sec³x）需移项合并，别陷入死循环。
  3. 易漏常数 C 与回代。

### §3 有理函数的积分

- **核心定义**：
  - 有理函数 = P(x)/Q(x)，P、Q 为多项式。若 deg P ≥ deg Q 先**多项式除法**化为多项式+真分式。
  - 真分式按 Q(x) 因式分解作**部分分式拆分**。

- **关键定理/公式**（四种拆分情形，Q 在实根范围分解）：
  1. 单重一次因式 (x-a)：对应项 A/(x-a)。
  2. k 重一次因式 (x-a)^k：对应 Σ_{i=1}^k A_i/(x-a)^i。
  3. 单重二次质因式 (x²+px+q)（判别式<0）：对应 (Bx+C)/(x²+px+q)。
  4. k 重二次质因式：对应 Σ_{i=1}^k (B_i x+C_i)/(x²+px+q)^i。
  拆分后用待定系数法求常数，再逐项积分（一次式→ln，二次式→arctan 或 ln）。

- **典型例题**：
  **例** 求 ∫(2x+3)/((x+1)(x+2)) dx。
  **解**：设 (2x+3)/((x+1)(x+2)) = A/(x+1)+B/(x+2)。通分得 2x+3=A(x+2)+B(x+1)。令 x=-1：1=A·1 ⇒ A=1；x=-2：-1=B·(-1) ⇒ B=1。原式=∫[1/(x+1)+1/(x+2)]dx = ln|x+1|+ln|x+2|+C = ln|x²+3x+2|+C。

- **易错点**：
  1. 假分式**先除后拆**，不可直接拆。
  2. 重因式要拆成各次幂之和，易漏高次幂项。

### §4 三角函数有理式的积分

- **核心定义**：
  - 三角函数有理式 R(sin x, cos x) 的积分 ∫R(sin x, cos x)dx，可用**万能代换** t=tan(x/2) 化为有理函数积分。

- **关键定理/公式**：
  1. 万能代换：t=tan(x/2)，则
     $$\sin x=\frac{2t}{1+t^2},\quad \cos x=\frac{1-t^2}{1+t^2},\quad dx=\frac{2}{1+t^2}dt$$
  2. 代价：代换后常出现高次有理式，计算繁琐；能先化简为好（如奇偶、对称性、积化和差）。

- **典型例题**：
  **例** 求 ∫ dx/(2+cos x)。
  **解**：令 t=tan(x/2)，cos x=(1-t²)/(1+t²)，dx=2dt/(1+t²)。原式=∫ [2/(1+t²)] / [2+(1-t²)/(1+t²)] dt = ∫ 2 / [2(1+t²)+1-t²] dt = ∫ 2/(3+t²) dt = (2/√3) arctan(t/√3)+C = (2/√3) arctan( tan(x/2)/√3 )+C。

- **易错点**：万能代换虽"万能"但**未必最简**，先观察是否有更简路径（如 ∫sin²x cos x dx 直接凑微分为 u=sin x）。

### §5 简单无理函数的积分

- **核心定义**：
  - 含根式的积分，通过适当代换化为有理或易积形式。

- **关键定理/公式**：
  1. 含 √(ax+b)：令 t=√(ax+b) ⇒ x=(t²-b)/a，dx=(2t/a)dt。
  2. 含 √(ax+b)、√(cx+d)：令 t 为二者公度根式（如令 t=√(ax+b) 再看 cx+d 是否可表）。
  3. 含 √(ax²+bx+c)：优先配方后用三角代换或欧拉代换。
  4. 含根式且分子分母含 x 的有理式：可试 t=√(…) 或倒代换。

- **典型例题**：
  **例** 求 ∫ dx/(1+√x)。
  **解**：令 t=√x，x=t²，dx=2t dt。原式=∫2t/(1+t) dt = 2∫(1-1/(1+t))dt = 2(t - ln|1+t|)+C = 2(√x - ln(1+√x))+C。

- **易错点**：代换后注意**全式替换**（x 与 dx 都要换），回代时不要残留 t。

## 三、常见题型与解题套路

| 题型 | 识别特征 | 首选方法 | 备选方法 | 陷阱 |

## 四、易错点清单

1. **错误做法**：不定积分结果不写 +C → **正确做法**：任何不定积分末尾加任意常数 C → **原因**：不定积分是全体原函数。
2. **错误做法**：∫(1/x)dx 写成 ln x 不写绝对值 → **正确做法**：ln|x|+C → **原因**：定义域含负半轴。
3. **错误做法**：凑微分后保留中间变量 u → **正确做法**：代回原变量 x → **原因**：答案须为 x 的函数。
4. **错误做法**：分部选 u 不当导致越积越繁 → **正确做法**：按"反对幂三指"优先选 u → **原因**：使 ∫v du 更简单。
5. **错误做法**：循环型分部陷入死循环 → **正确做法**：两次分部后移项合并原式 → **原因**：出现 I=...±I 形式。
6. **错误做法**：假分式直接部分分式拆分 → **正确做法**：先做多项式除法化为整式+真分式 → **原因**：部分分式仅对真分式。
7. **错误做法**：三角代换回代用错反三角函数 → **正确做法**：借助直角三角形还原 x=a sin t ⇒ t=arcsin(x/a) → **原因**：区间限定保证单调可逆。
8. **错误做法**：万能代换不经判断硬套 → **正确做法**：先看能否凑微分/积化和差化简 → **原因**：万能代换常致高次繁式。
9. **错误做法**：倒代换漏处理 |t| 符号 → **正确做法**：按 x 正负决定回代绝对值 → **原因**：√(1/t²)=1/|t|。
10. **错误做法**：把 ∫f(x)g(x)dx 当 ∫f·∫g → **正确做法**：用分部或换元，不可拆乘积 → **原因**：积分对加法线性，对乘法不线性。

## 五、经济应用

不定积分在经管类中的直接应用主要是**由边际函数反求总量函数**：
- 已知边际成本 MC(x)=C'(x)，则成本函数 C(x)=∫MC(x)dx + C₀，C₀ 由固定成本（如 C(0)）确定。
- 已知边际收益 MR(x)=R'(x)，则收益 R(x)=∫MR(x)dx + R(0)（通常 R(0)=0）。
- 已知边际利润 ML(x)，则利润 L(x)=∫ML(x)dx + L(0)。
- 例：若边际成本 MC=3+0.2x，固定成本 C(0)=50，则 C(x)=∫(3+0.2x)dx+50=3x+0.1x²+50。
- 说明：积分常数对应"初始/固定"量，是经济含义的落点，讲解时务必点明 C 的经济意义。
