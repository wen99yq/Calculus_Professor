# 可视化绘图指南

> 微积分里很多结论"画出来就懂了"。本文件规定 `Calculus_Professor` 画图的场景、规范与配方。
> 原则：**图必须直接支撑要讲的结论**；不画装饰性插画。

---

## 一、什么时候画图

| 知识点 | 该画的图 | 类型 |
|---|---|---|
| 极限的直观 | 函数图像 + 趋近过程 | 内联 SVG |
| 导数定义 | 割线 → 切线趋近 | **交互 HTML**（可拖 h） |
| 导数的几何意义 | 某点切线 + 斜率三角形 | 内联 SVG |
| 微分 | 局部线性化的放大 | 内联 SVG |
| 单调性与极值 | 函数 + 导数符号区间 | 内联 SVG |
| 凹凸性与拐点 | 曲线 + 切线在曲线上/下 | 内联 SVG |
| 渐近线 | 曲线 + 水平/垂直渐近线 | 内联 SVG |
| 定积分定义 | 黎曼和 n 增大逼近 | **交互 HTML**（可拖 n） |
| 曲边梯形面积 | 阴影区域 + 上下限标注 | 内联 SVG |
| 定积分换元 | 换元前后上下限对应 | 内联 SVG（数轴） |
| 旋转体体积 | 圆盘 / 柱壳示意 | 内联 SVG（剖面） |
| 广义积分 | 无限延伸区域 + 收敛/发散对比 | 内联 SVG |
| 一阶微分方程 | 方向场 + 积分曲线 | 内联 SVG |
| 弹性分析 | 需求曲线 + 收益随价变化 | **交互 HTML** 或内联 SVG |
| 学习报告 | 错题分布、掌握度、进步趋势 | Chart.js（报告 HTML 内） |

**判断标准**：这个结论如果学生能"在脑子里看见"，就不用画；如果他说"我算出来了但还是不懂为什么"，就画。

## 二、内联 SVG 规范

在对话中直接渲染的图，用内联 SVG。

### 2.1 基础约束

- `viewBox="0 0 680 H"` —— **680 是固定宽度**，所有坐标基于它计算；`H` = 最底部元素 + 20
- 根 `<svg>` 上写 `width="100%"`
- 安全区：`x: 40 → 640`，`y: 40 → H-40`
- **背景透明**（不要给外层画深色/彩色底，宿主提供背景）
- 边框与坐标轴用 `0.5px` 描边；函数曲线用 `1.5~2px`
- 每个 `<path>` / `<polyline>` 当连接线用时必须 `fill="none"`
- 字号 **不小于 11px**；不使用 emoji
- 不要渐变、阴影、发光；不用 `position: fixed`
- 图的**说明文字写在回复正文里**，不要塞进 SVG

### 2.2 主题适配（重要）

**对话内的 SVG 必须用 CSS 变量取色**，才能跟随亮/暗主题：

| 用途 | 用色 |
|---|---|
| 坐标轴、网格线 | `var(--color-border-tertiary)` / `-secondary` |
| 刻度数字、轴标签 | `var(--color-text-secondary)` |
| 关键标注、结论文字 | `var(--color-text-primary)` |
| 主曲线 | 显式 hex（见下）— 曲线需要辨识度 |
| 强调区域（阴影） | 显式 hex + `fill-opacity="0.15"` |

主曲线配色（亮暗主题通用，取中等明度）：

| 语义 | hex |
|---|---|
| 主函数曲线 | `#378ADD`（蓝） |
| 切线 / 导数相关 | `#D85A30`（珊瑚） |
| 割线 / 辅助线 | `#888780`（灰） |
| 阴影面积 / 积分区域 | `#7F77DD`（紫） |
| 关键点（极值、拐点） | `#D4537E`（粉） |
| 正确 / 收敛 | `#639922`（绿） |
| 警告 / 发散 / 易错 | `#E24B4A`（红） |

> 不要给 `<text>` 写死黑色或白色 —— 暗色主题下会看不见。

### 2.3 坐标系配方

```svg
<svg viewBox="0 0 680 380" width="100%" role="img" xmlns="http://www.w3.org/2000/svg">
  <title>函数 y = x² 在 x = 1 处的切线</title>
  <desc>抛物线及其在点 (1,1) 处斜率为 2 的切线</desc>
  <defs>
    <marker id="arrow" viewBox="0 0 10 10" refX="8" refY="5"
      markerWidth="6" markerHeight="6" orient="auto-start-reverse">
      <path d="M2 1L8 5L2 9" fill="none" stroke="context-stroke"
        stroke-width="1.5" stroke-linecap="round" stroke-linejoin="round"/>
    </marker>
  </defs>

  <!-- 坐标轴：原点定在 (340, 300)，x 向右，y 向上 -->
  <line x1="40" y1="300" x2="640" y2="300" stroke="var(--color-border-secondary)" stroke-width="0.5" marker-end="url(#arrow)"/>
  <line x1="340" y1="340" x2="340" y2="50" stroke="var(--color-border-secondary)" stroke-width="0.5" marker-end="url(#arrow)"/>
  <text class="ts" x="636" y="320" text-anchor="end">x</text>
  <text class="ts" x="352" y="56">y</text>
  <text class="ts" x="352" y="318">O</text>
</svg>
```

**坐标映射公式**（手算或交给 `scripts/plot_svg.py`）：

```
px = x0 + (x - xmin) / (xmax - xmin) * plot_width
py = y0 - (y - ymin) / (ymax - ymin) * plot_height
```

其中 `plot_width = 600`（即 680 − 左右各 40），`plot_height` 按需要定，原点 `(x0, y0)` 依 xmin/xmax 是否跨零决定。

### 2.4 曲线点列不要手算

曲线用 `<polyline points="x1,y1 x2,y2 ..." fill="none">` 绘制。**点列必须由脚本生成**，手算容易变形：

```bash
python "scripts/plot_svg.py" --expr "x^2" --xmin -2 --xmax 2 --samples 60
```

脚本输出可直接粘贴的 `points="..."` 字符串（以及可选的完整 SVG 片段）：

```
--mode points     只输出 points 点列
--mode svg        输出完整可用的 SVG 片段（含坐标轴与网格）
--points-at x=1   额外标出某点的坐标（用于切线、极值点）
--width 600 --height 260 --ymin -1 --ymax 4
```

多曲线叠加时，每条曲线各跑一次，取 `--mode points` 后拼进同一个 SVG。

### 2.5 标注要素

| 要素 | 画法 |
|---|---|
| 函数标签 | 曲线末端附近放 `class="ts"` 文本，如 `y = x²`，**不要**压在曲线上 |
| 关键点 | 实心圆 `r="4"`，填对应语义色 |
| 切线斜率三角形 | 虚线直角边 + `Δy` / `Δx` 标注 |
| 阴影面积 | `fill` + `fill-opacity="0.15"`，边缘 `stroke` 用同色系深一档 |
| 积分上下限 | 在 x 轴上引虚线到曲线，轴上标 `a`、`b` |
| 引导线 | 0.5px 虚线（`stroke-dasharray="3 3"`） |

## 三、交互 HTML（参数联动）

### 3.1 什么时候用

学生需要**看到参数变化带来的连锁反应**时：

- 拖 `h` 看割线趋于切线（导数定义）
- 拖 `n` 看黎曼和逼近定积分
- 拖 `a, b` 看 y = a·sin(bx) 的变换
- 拖需求弹性看总收益随价格的变化
- 拖 λ 看 Logistic 曲线的陡缓

### 3.2 技术约束

- **单文件、离线可用**：样式与脚本内联，**不引用外部 CDN**（学生可能断网）
- 用原生 `<input type="range">` + 手写 SVG 重绘；不要为了拖拽引入数学库
- **不能依赖宿主 CSS 变量**（文件是独立打开的）→ 自带样式，并用
  `@media (prefers-color-scheme: dark)` 适配系统深浅色
- 至少包含：图、参数滑块、实时数值显示、一句结论文字
- 保存到 `微积分学习/报告/` 并在回复中给出文件路径，然后用 present_files 呈现

### 3.3 结构模板

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
<meta charset="utf-8">
<meta name="viewport" content="width=device-width, initial-scale=1">
<title>割线趋于切线</title>
<style>
  :root { --bg:#ffffff; --fg:#1c1c1c; --muted:#666; --line:#d8d8d8; --curve:#378ADD; --sec:#888780; }
  @media (prefers-color-scheme: dark) {
    :root { --bg:#1c1c1c; --fg:#f0f0f0; --muted:#a8a8a8; --line:#3a3a3a; }
  }
  body { margin:0; padding:16px; background:var(--bg); color:var(--fg);
         font:13px/1.6 system-ui, -apple-system, "Segoe UI", "Microsoft YaHei", sans-serif; }
  .row { display:flex; align-items:center; gap:12px; margin:12px 0; }
  .val { font-variant-numeric: tabular-nums; min-width:72px; }
  .concl { color:var(--muted); }
</style>
</head>
<body>
<h2 style="font-size:15px;font-weight:500;margin:0 0 12px">割线如何趋于切线（导数定义）</h2>
<svg id="fig" viewBox="0 0 680 300" width="100%" aria-label="抛物线上的割线随 h 减小趋于切线"></svg>
<div class="row">
  <label for="h">h =</label>
  <input id="h" type="range" min="0.05" max="2" step="0.05" value="1.5" style="flex:1">
  <span class="val" id="hv">1.50</span>
</div>
<p class="concl">当 h → 0 时，割线斜率 → 切线斜率 2。</p>
<script>
(function(){
  var SVG_NS = "http://www.w3.org/2000/svg";
  var X0=60, Y0=250, W=560, H=200, XMIN=-1, XMAX=3, YMIN=-1, YMAX=5;
  function px(x){ return X0 + (x-XMIN)/(XMAX-XMIN)*W; }
  function py(y){ return Y0 - (y-YMIN)/(YMAX-YMIN)*H; }
  var f = function(x){ return x*x; };
  // ... 绘制坐标轴、抛物线、割线、切点；h 变化时重绘割线
})();
</script>
</body>
</html>
```

### 3.4 交互质量要求

- 滑块拖动时**实时更新**，不卡顿（点数控制在 120 以内）
- 数值显示保留 2 位小数，且**四舍五入**
- 极值/极限情形要有明确提示（如 `h` 很小时显示"已近似为切线"）
- 移动端可用：`width:100%`、触摸可拖、字号不小于 12px

## 四、报告中的数据图（Chart.js）

学习报告是独立 HTML，允许通过 **CDN 白名单**加载脚本（`cdnjs.cloudflare.com`、`esm.sh`、`cdn.jsdelivr.net`、`unpkg.com`）：

- 错题分布（按章）→ 横向条形图，条数 ≤ 8
- 掌握度分布 → 条形图或环形图
- 进步趋势（历次练习正确率）→ 折线图
- 每个 `<canvas>` 必须有 `role="img"` + `aria-label` + 兜底文本
- 坐标轴刻度用 `.toFixed(0)` 等取整；不使用默认图例，用自定义 HTML 图例
- 横向条形图的容器高度 = 条数 × 40 + 80 px

> 报告若需**完全离线**，则把 Chart.js 代码内联进 HTML，或改用内联 SVG 画条形图。
> 默认策略：**报告优先离线**（内联 SVG 条形图），除非学生明确要求交互图表。

## 五、禁止事项

- ❌ 图与结论无关（纯装饰）
- ❌ 手算曲线点列导致图形失真
- ❌ 给文字写死黑/白色，导致暗色主题看不见
- ❌ 外链图片或 CDN（对话内 SVG 与交互 HTML 均禁止；报告允许白名单 CDN）
- ❌ 在 SVG 里塞大段说明文字（正文说，图只标关键量）
- ❌ 一屏多个图堆叠却没有过渡文字 —— 图之间必须有解释
- ❌ 用 3D 透视画旋转体却不标半径函数
