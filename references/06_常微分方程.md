## 一、逐节知识速查

### § 微分方程的基本概念
- **核心定义**：含未知函数及其导数（或微分）的方程称为微分方程；未知函数是一元函数的称**常**微分方程。方程中出现的**最高阶导数**的阶数称为方程的**阶**。使方程恒等成立的已知函数称为**解**；含独立任意常数且个数=阶数的解为**通解**；由初始条件确定常数得到的解为**特解**；解对应的曲线称为**积分曲线**。
- **关键定理/公式**：
  1. n 阶方程的通解含 n 个独立任意常数；n 个初始条件可确定特解。
  2. 线性微分方程解的结构（见后文常系数部分）。
- **典型例题**：
  - **例1** 验证 y=C₁e^{x}+C₂e^{−x} 是 y''−y=0 的通解，并由 y(0)=0、y'(0)=1 求特解。
  - **解** 代回可验 y''−y=(C₁e^{x}+C₂e^{−x})−(C₁e^{x}+C₂e^{−x})=0。由 y(0)=C₁+C₂=0，y'=C₁e^{x}−C₂e^{−x}，y'(0)=C₁−C₂=1，解得 C₁=1/2、C₂=−1/2，特解 y=(e^{x}−e^{−x})/2。
- **易错点**：
  1. 通解中"独立"任意常数个数必须等于阶数；多写或少写都不算通解。
  2. 初始条件数量应与阶数一致，且应作用在 y 及其各阶导数上。

### § 可分离变量方程
- **核心定义**：能化为 g(y)dy = h(x)dx 形式的方程。
- **关键定理/公式**：
  1. 标准形式：$\frac{dy}{dx}=f(x)g(y)$，分离得 $\frac{dy}{g(y)}=f(x)dx$，两边积分得 ∫dy/g(y)=∫f(x)dx + C。
  2. 注意 g(y)=0 的常数解也需单独列出。
- **典型例题**：
  - **例2** 解方程 dy/dx = 2xy。
  - **解** 分离：dy/y = 2x dx（y≠0）。积分 ln|y| = x² + C₁，即 |y|=e^{C₁}e^{x²}，故 y = C e^{x²}（C 任意实常数，含 y=0 情形）。
- **易错点**：
  1. 除以 g(y) 时忽略 g(y)=0 对应的常数解，导致漏解。
  2. 任意常数写成 ln C 形式时 C 应 > 0，但合并后吸收符号可得任意常数，需说明。

### § 齐次方程
- **核心定义**：形如 dy/dx = φ(y/x) 的一阶方程。
- **关键定理/公式**：
  1. 令 u = y/x（即 y = ux，dy/dx = u + x du/dx），化为可分离变量：x du/dx = φ(u) − u，即 du/(φ(u)−u) = dx/x。
- **典型例题**：
  - **例3** 解 dy/dx = (y+x)/(y−x)。
  - **解** 分子分母同除以 x 得 dy/dx = (y/x+1)/(y/x−1) = φ(y/x)。令 u=y/x，则 u + x u' = (u+1)/(u−1)，x u' = (u+1)/(u−1) − u = (u+1−u²+u)/(u−1) = (2u+1−u²)/(u−1)。分离积分 ∫(u−1)/(−u²+2u+1) du = ∫dx/x，解得 ln|−u²+2u+1| = −2 ln|x| + C，回代即可。
- **易错点**：
  1. 齐次方程指 φ(y/x) 型，与"齐次线性"是不同的概念，勿混淆。
  2. 代换后务必回代 u=y/x，且注意 x≠0。

### § 一阶线性微分方程
- **核心定义**：形如 y' + P(x)y = Q(x) 的方程；Q≡0 时为齐次，否则非齐次。
- **关键定理/公式**：
  1. 通解公式（公式法）：
     $$y = e^{-\int P(x)dx}\left(\int Q(x)e^{\int P(x)dx}dx + C\right)$$
  2. 常数变易法：先解齐次 y'+P y=0 得 y₁=Ce^{−∫Pdx}；令 y = C(x)e^{−∫Pdx} 代入原方程定 C(x)。
- **典型例题**：
  - **例4** 解 y' + y = e^{−x}。
  - **解** P=1，Q=e^{−x}。积分因子 e^{∫1 dx}=e^{x}。公式：y=e^{−x}(∫e^{−x}e^{x}dx + C)=e^{−x}(∫1 dx + C)=e^{−x}(x+C)。
- **易错点**：
  1. 必须先把方程化为标准形式 y'+P(x)y=Q(x)（y' 系数为 1）再套公式，否则 P 易取错。
  2. 积分因子中的 ∫Pdx 取一个原函数即可，不必带常数 C（常数已包含在最终 +C 中）。

### § 伯努利方程
- **核心定义**：形如 y' + P(x)y = Q(x)y^{n}（n≠0,1）的方程。
- **关键定理/公式**：
  1. 令 z = y^{1−n}，则 z' = (1−n)y^{−n}y'，方程化为一阶线性：z' + (1−n)P(x)z = (1−n)Q(x)。
- **典型例题**：
  - **例5** 简述 y' + y = y² 的化简。
  - **解** n=2，令 z=y^{−1}，则 z' = −y^{−2}y'，得 −z' + z = 1，即 z' − z = −1，按一阶线性解出 z 后回代 y=1/z。
- **易错点**：
  1. 仅当 n≠0,1 时称伯努利；n=0 或 1 已是线性方程。
  2. 代换 z=y^{1−n} 后系数含 (1−n)，勿遗漏。

### § 可降阶的高阶方程
- **核心定义**：三类可通过代换降阶的方程。
- **关键定理/公式**：
  1. **y'' = f(x) 型**：直接两次积分；或令 p=y' 得 p' = f(x)。
  2. **y'' = f(x,y') 型**（缺 y）：令 p=y'，则 y'' = p'，化为 p' = f(x,p)（一阶）。
  3. **y'' = f(y,y') 型**（缺 x）：令 p=y'，则 y'' = dp/dx = (dp/dy)(dy/dx) = p dp/dy，化为 p dp/dy = f(y,p)（一阶）。
- **典型例题**：
  - **例6** 解 y'' = x + e^{x}。
  - **解** 一次积分 y' = x²/2 + e^{x} + C₁；二次积分 y = x³/6 + e^{x} + C₁x + C₂。
- **易错点**：
  1. "缺 y"型用 p=y'、y''=p'；"缺 x"型用 y''=p dp/dy，二者代换不同，勿混。
  2. 降阶后若解 p 得到 y' 表达式，还需再积分一次并补足常数。

### § 二阶常系数齐次线性微分方程
- **核心定义**：形如 y'' + py' + qy = 0（p,q 常数）的方程。
- **关键定理/公式**：
  1. 特征方程：r² + pr + q = 0，根 r₁、r₂ 决定通解：
     - 两不等实根 r₁≠r₂：$y = C_1 e^{r_1 x} + C_2 e^{r_2 x}$
     - 重根 r₁=r₂=r：$y = (C_1 + C_2 x)e^{r x}$
     - 共轭复根 r=α±iβ：$y = e^{\alpha x}(C_1\cos\beta x + C_2\sin\beta x)$
- **典型例题**：
  - **例7** 解 y'' − 3y' + 2y = 0。
  - **解** 特征方程 r²−3r+2=0，根 r=1,2。通解 y = C₁e^{x} + C₂e^{2x}。
- **易错点**：
  1. 复根情形通解是 e^{αx} 乘以三角组合，不是 e^{(α+iβ)x} 的复数形式（实数域解用实部/虚部组合）。
  2. 特征方程必须由"y''、y'、y 系数"正确写出，符号易错（r² + pr + q）。

### § 二阶常系数非齐次线性微分方程
- **核心定义**：y'' + py' + qy = f(x)，用"齐次通解 + 非齐次特解"得通解。
- **关键定理/公式**（待定系数法）：
  1. 若 f(x) = P_m(x)e^{λx}（P_m 为 m 次多项式），设特解 $y^* = x^k Q_m(x)e^{\lambda x}$，其中 Q_m 为待定 m 次多项式；k=0（λ 非特征根）、k=1（λ 是单特征根）、k=2（λ 是重特征根）。
  2. 若 f(x) = e^{λx}(A cos ωx + B sin ωx)，设 $y^* = x^k e^{\lambda x}(C\cos\omega x + D\sin\omega x)$；k=0（λ±iω 非特征根）、k=1（是特征根）。
- **典型例题**：
  - **例8** 解 y'' − y = e^{x}。
  - **解** 齐次特征 r²−1=0 ⇒ r=±1，齐次通解 C₁e^{x}+C₂e^{−x}。f=e^{x}，λ=1 是单特征根，故设 y*=x·a e^{x}。代入：y*'=a e^{x}(1+x)，y*''=a e^{x}(2+x)，y*''−y* = a e^{x}(2+x) − a x e^{x} = 2a e^{x} = e^{x} ⇒ a=1/2。特解 y*=(x e^{x})/2，通解 y=C₁e^{x}+C₂e^{−x}+xe^{x}/2。
- **易错点**：
  1. k 的取值由 λ 与特征根的关系决定，漏乘 x^k 会导致特解与齐次解线性相关、无法求出。
  2. f 为三角组合时特解须同时设 cos 与 sin 两项，缺一不可（即使原式只含一项）。

### § 微分方程的经济应用
- **核心定义**：用微分方程刻画经济变量随时间演化的动态模型（详见第五节）。
- **关键定理/公式**：见第五节 Logistic、价格调整、供需均衡模型。
- **典型例题**：
  - **例9** 某商品需求量 Q 对价格 p 的调整满足 dp/dt = k(D(p)−S(p))（k>0），简述均衡稳定性。
  - **解** 在均衡价格 p* 处 D(p*)=S(p*)。若 D'(p)<S'(p)（超额需求随价格升而降），线性化后 dp/dt≈k(D'(p*)−S'(p*))(p−p*)<0 当 p>p*，价格自动回落，均衡稳定。
- **易错点**：
  1. 动态模型中"稳定性"需考察扰动后是否回归均衡，不能只看均衡点存在。
  2. 建模时变量与参数单位要一致，增长率/调整速度 k 的符号决定演化方向。

## 四、易错点清单
1. **错误做法**：通解任意常数个数与阶数不符。→ **正确做法**：n 阶方程通解恰含 n 个独立任意常数。→ **原因**：每积分一次引入一个常数。
2. **错误做法**：分离变量时忽略 g(y)=0 的常数解。→ **正确做法**：列出 g(y)=0 对应的特解。→ **原因**：除以 g(y) 已排除其为 0 的可能。
3. **错误做法**：套一阶线性公式前未把 y' 系数化为 1。→ **正确做法**：先除以 y' 的系数再读 P、Q。→ **原因**：公式要求标准形式。
4. **错误做法**：齐次方程与齐次线性方程混淆。→ **正确做法**：前者指 φ(y/x) 型一阶方程，后者指右端为 0 的线性方程。→ **原因**：同名不同对象。
5. **错误做法**：降阶时"缺 y"与"缺 x"用同一代换。→ **正确做法**：缺 y 用 p=y'、p'=y''；缺 x 用 y''=p dp/dy。→ **原因**：变量依赖不同。
6. **错误做法**：特征方程写成 r²−pr+q 或符号错。→ **正确做法**：y''+py'+qy=0 对应 r²+pr+q=0。→ **原因**：系数符号直接照搬。
7. **错误做法**：复根通解写成 e^{(α+iβ)x}。→ **正确做法**：取实部/虚部组合 e^{αx}(C₁cosβx+C₂sinβx)。→ **原因**：要求实值解。
8. **错误做法**：非齐次特解漏乘 x^k（k 视 λ 与特征根关系取 0/1/2）。→ **正确做法**：λ 非根 k=0，单根 k=1，重根 k=2。→ **原因**：否则特解与齐次解线性相关。
9. **错误做法**：f 为三角项只设单一 cos 或 sin。→ **正确做法**：同时设 C cosωx + D sinωx。→ **原因**：导数会混合两项。
10. **错误做法**：经济模型中只求均衡点不判稳定性。→ **正确做法**：线性化后看扰动回归方向。→ **原因**：稳定比存在更重要。

## 五、经济应用
1. **Logistic 增长模型（阻滞增长）**
   - 基本假设：增长率随规模接近容纳量 K 而下降。
   - 方程：$\frac{dx}{dt}=rx\left(1-\frac{x}{K}\right)$，其中 r>0 为内禀增长率，K>0 为环境容纳量。
   - 求解（分离变量）：
     $$\int\frac{dx}{x(1-x/K)}=\int r\,dt \;\Rightarrow\; \ln\frac{x}{K-x}=rt+C$$
     得 $x(t)=\frac{K}{1+Ce^{-rt}}$（常数由初值 x(0) 定）。
   - 性质：x(0)<K 时单调增趋于 K；x(0)>K 时单调减趋于 K；K 是稳定均衡。
   - 应用：人口、市场饱和、传染病的受限扩散等。

2. **价格调整模型（蛛网/动态定价）**
   - 设超额需求推动价格变化：$\frac{dp}{dt}=k\big(D(p)-S(p)\big)$，k>0 为调整速度。
   - 线性情形 D(p)=a−bp、S(p)=c+dp（a,b,c,d>0），均衡 p*=(a−c)/(b+d)。
   - 线性化：dp/dt ≈ k(−(b+d))(p−p*)，解为 p(t)=p*+C e^{−k(b+d)t}，指数回归均衡，**稳定**。
   - 含义：若需求随价格降、供给随价格升（b,d>0），市场动态调整收敛于均衡。

3. **供需均衡动态模型（含预期/库存）**
   - 更一般形式：供应量依赖价格变化率或滞后价格，如 $\frac{dp}{dt}=k(D(p_t)-S(p_{t-\tau}))$（含时滞 τ）。
   - 无时滞且 D' < S'（需求曲线比供给曲线更平缓）时均衡稳定；时滞过大会引起振荡甚至失稳。
   - 教学要点：稳定性取决于 D、S 斜率相对大小与调整速度 k，而非均衡价格本身。

4. **连续复利与资本积累（补充）**
   - 若资本存量 K 的变化率 = 投资率 I(t) − 折旧率 δK，则 dK/dt = I(t) − δK，为一阶线性方程，可套公式求解，体现微分方程在宏观动态中的运用。
