## 一、逐节知识速查

### §1 微分中值定理

- **核心定义**：
  - 费马引理：若 f(x) 在 x₀ 处可导且 x₀ 为 f 的极值点（局部最大或最小），则 f'(x₀)=0。称导数为零的点为**驻点（稳定点）**。
  - 罗尔定理条件：① f 在 [a,b] 连续；② f 在 (a,b) 可导；③ f(a)=f(b)。结论：存在 ξ∈(a,b) 使 f'(ξ)=0。
  - 拉格朗日中值定理（Lagrange）条件：① f 在 [a,b] 连续；② f 在 (a,b) 可导。结论：存在 ξ∈(a,b) 使
    $$f'(\xi)=\frac{f(b)-f(a)}{b-a}$$
    或写成 f(b)-f(a)=f'(ξ)(b-a)（有限增量公式）。
  - 柯西中值定理（Cauchy）条件：① f、g 在 [a,b] 连续；② f、g 在 (a,b) 可导；③ g'(x)≠0（x∈(a,b)）。结论：存在 ξ∈(a,b) 使
    $$\frac{f(b)-f(a)}{g(b)-g(a)}=\frac{f'(\xi)}{g'(\xi)}$$

- **关键定理/公式**：
  1. 拉格朗日定理推论 1：若 f'(x)≡0 于区间 I，则 f(x) 在 I 上恒为常数。
  2. 拉格朗日定理推论 2：若 f'(x)=g'(x) 于区间 I，则 f(x)-g(x)=C（常数）。
  3. 罗尔定理的几何意义：满足三点条件的曲线，弧段内至少有一点切线水平。
  4. 拉格朗日定理几何意义：曲线弧上存在一点切线平行于弦 AB。

- **典型例题**：
  **例1** 验证 f(x)=x²-3x+2 在 [0,3] 上满足罗尔定理，并求 ξ。
  **解**：f 为多项式，在 R 连续可导，故在 [0,3] 连续、(0,3) 可导；且 f(0)=2，f(3)=9-9+2=2，即 f(0)=f(3)，满足三条件。令 f'(x)=2x-3=0 ⇒ x=3/2∈(0,3)，故 ξ=3/2。

  **例2** 证明：对 a<b，有 |sin b - sin a| ≤ |b-a|。
  **解**：令 f(x)=sin x，在 [a,b] 连续可导。由拉格朗日中值定理，存在 ξ∈(a,b) 使 sin b - sin a = cos ξ·(b-a)。两边取绝对值得 |sin b - sin a| = |cos ξ|·|b-a| ≤ 1·|b-a| = |b-a|。

- **易错点**：
  1. 用罗尔/拉格朗日前必须**先验证条件**（闭区间连续、开区间可导），缺一项结论即可能不成立。
  2. 拉格朗日中值定理中的 ξ 一般**与 a,b 有关且不能具体求出**，只保证存在。
  3. 柯西中值定理分母是 g(b)-g(a)，不是 (b-a)；且需保证 g'(x)≠0。

### §2 未定式的极限（洛必达法则）

- **核心定义**：
  - 称极限 lim f(x)/g(x) 为未定式，当分子分母同趋于 0（0/0）或同趋于无穷（∞/∞）。
  - 洛必达法则（0/0 型）：设① lim f(x)=lim g(x)=0；② 在极限点去心邻域内 f、g 可导且 g'(x)≠0；③ lim f'(x)/g'(x)=A（有限或 ∞）。则
    $$\lim \frac{f(x)}{g(x)}=\lim \frac{f'(x)}{g'(x)}=A$$

- **关键定理/公式**：
  1. 0/0 型洛必达（如上）。
  2. ∞/∞ 型洛必达：设 lim f(x)=∞、lim g(x)=∞，且 lim f'(x)/g'(x)=A，则 lim f/g=A。（注意：∞/∞ 条件下通常只需 f、g 可导、g'≠0，不要求先趋于 ∞ 的严格构造，按教材版本略有差异，结论成立。）
  3. 其他类型化归：
     - 0·∞ = 0·(1/0) ⇒ 改写为 0/0 或 ∞/∞；
     - ∞-∞ ⇒ 通分或有理化化为分式；
     - 幂指型 0⁰、1⁰、∞⁰ ⇒ 取对数令 y=f(x)^g(x)，ln y=g(x)ln f(x) 化为 0·∞ 再处理。

- **典型例题**：
  **例1** 求 lim_{x→0} (e^x - e^{sin x}) / (x - sin x)。
  **解**：0/0 型。分子 e^x - e^{sin x} = e^{sin x}(e^{x-sin x}-1) ~ x-sin x，故原式 = lim e^{sin x}·(x-sin x)/(x-sin x) = 1。亦可用洛必达：分子导 e^x - e^{sin x}cos x，分母导 1-cos x，再次洛必达后得 1。（注意：此例反复洛必达会变复杂，观察等价无穷小更简。）

  **例2** 求 lim_{x→+∞} x/e^x。
  **解**：∞/∞ 型。洛必达：lim x'/(e^x)' = lim 1/e^x = 0。

- **易错点**：
  1. **非未定式不能用洛必达**：如 lim (x+1)/x → 1，若误当 ∞/∞ 对分子分母求导得 lim 1/1=1，虽结果巧合对，但过程错误；更危险的是 lim (x+sin x)/x = 1+0=1，若错用洛必达得 lim (1+cos x)/1 不存在，得出"极限不存在"的错结论。
  2. 洛必达后 lim f'/g' **不存在（且非 ∞）**时，法则失效，但原极限可能存在，须换法（如等价无穷小、夹逼）。
  3. 每次使用前需重新确认仍为 0/0 或 ∞/∞，不能连续乱套。
  4. 0·∞、∞-∞ 必须**先化简/转化**再判型，直接洛必达无意义。

### §3 泰勒定理与应用

- **核心定义**：
  - 带拉格朗日余项的泰勒公式（在 x₀ 处，n 阶）：若 f 在含 x₀ 的区间有 n+1 阶连续导数，
    $$f(x)=\sum_{k=0}^{n}\frac{f^{(k)}(x_0)}{k!}(x-x_0)^k+\frac{f^{(n+1)}(\xi)}{(n+1)!}(x-x_0)^{n+1}$$
    其中 ξ 在 x 与 x₀ 之间，最后一项为拉格朗日余项 R_n(x)。
  - 带佩亚诺余项的泰勒公式（x→x₀）：
    $$f(x)=\sum_{k=0}^{n}\frac{f^{(k)}(x_0)}{k!}(x-x_0)^k+o\big((x-x_0)^n\big)$$
    只要求 f 在 x₀ 处 n 阶可导，余项阶数表达为小 o。
  - x₀=0 时的泰勒公式称为**麦克劳林公式**。

- **关键定理/公式**（常用麦克劳林展开，R 为余项）：
  1. $e^x = 1+x+\dfrac{x^2}{2!}+\dfrac{x^3}{3!}+o(x^3)$；余项 $\dfrac{e^\xi}{(n+1)!}x^{n+1}$。
  2. $\sin x = x-\dfrac{x^3}{3!}+\dfrac{x^5}{5!}+o(x^5)$；或到 x³： $x-\dfrac{x^3}{6}+o(x^3)$。
  3. $\cos x = 1-\dfrac{x^2}{2!}+\dfrac{x^4}{4!}+o(x^4)$；或 $1-\dfrac{x^2}{2}+o(x^2)$。
  4. $\ln(1+x)=x-\dfrac{x^2}{2}+\dfrac{x^3}{3}+o(x^3)$。
  5. $(1+x)^\alpha=1+\alpha x+\dfrac{\alpha(\alpha-1)}{2!}x^2+o(x^2)$（二项式展开）。
  6. $\dfrac{1}{1-x}=1+x+x^2+x^3+o(x^3)$。

- **典型例题**：
  **例1** 用带佩亚诺余项的麦克劳林公式求 lim_{x→0} (x - sin x)/x³。
  **解**：sin x = x - x³/6 + o(x³)，故 x - sin x = x³/6 + o(x³)，原式 = lim (x³/6 + o(x³))/x³ = 1/6。

  **例2** 估计 e^0.1 用 1+0.1+0.1²/2 的误差。
  **解**：按 e^x 余项 R₂ = e^ξ/3! · x³，ξ∈(0,0.1)。误差 ≤ e^{0.1}/6 · 0.001 < 1.106/6·0.001 < 1.85×10⁻⁴。

- **易错点**：
  1. **拉格朗日余项**用于误差估计（需 n+1 阶导数有界）；**佩亚诺余项**只用于极限与定性分析（无需有界，仅局部）。
  2. 代换展开时只保留到所需阶：如求三阶极限，e^{2x} 须展开到 x³ 项，不可少项。
  3. 复合代入后注意"同类项"合并，避免丢项。

### §5 函数图形的凹凸性与拐点

- **核心定义**：
  - **凹（上凹/凸）**：曲线弧位于其任一点切线的上方；**凸（下凹）**：曲线弧位于切线的下方。（注：不同教材凹凸命名相反，讲解前先确认教材约定；本书按导数二阶符号判定。）
  - **拐点**：连续曲线上凹凸性发生改变的点。

- **关键定理/公式**：
  1. 若在 I 上 f''(x)>0，则曲线在 I 上是凹的；f''(x)<0 则为凸的。
  2. 若 (x₀,f(x₀)) 为拐点且 f''(x₀) 存在，则 f''(x₀)=0（寻找拐点的候选点）；但 f''(x₀)=0 未必是拐点（需左右二阶导变号）。

- **典型例题**：
  **例** 判断 f(x)=x³ 的凹凸与拐点。
  **解**：f''(x)=6x；当 x<0 时 f''<0（凸），x>0 时 f''>0（凹）。x=0 处 f''=0 且左右变号，故 (0,0) 为拐点。

- **易错点**：
  1. f''(x₀)=0 不是拐点的充分条件，必须验证两侧 f'' 异号。
  2. f'' 不存在的点也可能是拐点（如 f(x)=x^{1/3} 在 0 处）。

### §6 函数图形的描绘

- **核心定义**：
  - **渐近线**：
    - 水平渐近线：lim_{x→∞} f(x)=C ⇒ y=C。
    - 垂直渐近线：lim_{x→a} f(x)=∞（或 ±∞）⇒ x=a。
    - 斜渐近线 y=kx+b：k=lim_{x→∞} f(x)/x，b=lim_{x→∞}[f(x)-kx]；k 存在且非 0 时求 b。

- **关键定理/公式**：
  1. 斜渐近线求法：k=lim_{x→∞} f(x)/x，b=lim_{x→∞}[f(x)-kx]（x→+∞ 与 x→-∞ 分别考虑，可能不同）。
  2. 若 k=0，则退化为水平渐近线。

- **典型例题**：
  **例** 求 f(x)=(x²+1)/x 的渐近线。
  **解**：x=0 处 lim_{x→0} f(x)=∞ ⇒ 垂直渐近线 x=0。k=lim x/x=1（此处 x→∞ 时 f(x)/x = (x+1/x)/x = 1+1/x² → 1）；b=lim[(x+1/x)-x]=lim 1/x=0。故斜渐近线 y=x。无水平渐近线。

- **易错点**：
  1. 垂直渐近线找的是**使函数趋于无穷的间断点/端点**，不能只看分母为零处（如 sin x/x 在 0 处极限为 1，非垂直渐近）。
  2. 斜渐近与水平渐近互斥（同一方向）；x→±∞ 可能对应不同斜渐近线。

### §7 导数在经济中的应用

- **核心定义**：
  - 经济常用函数（设产量/销量为 x，价格为 p）：
    - 成本函数 C(x)=固定成本+可变成本；平均成本 $\bar C(x)=C(x)/x$。
    - 收益函数 R(x)=p·x（价格与量相关时 p=p(x)）。
    - 利润函数 L(x)=R(x)-C(x)。
    - 需求函数 Q=Q(p)（价格 p 的函数）。
  - **边际分析**：某经济函数 f(x) 对自变量 x 的导数 f'(x) 称为边际函数，表示 x 在边际（微小增量）处的瞬时变化率。
    - 边际成本 MC=C'(x)：多生产一单位产品时总成本近似的增加量。
    - 边际收益 MR=R'(x)。
    - 边际利润 ML=L'(x)=MR-MC。
  - **弹性分析**：需求对价格的弹性
    $$E=\frac{p}{Q}\cdot\frac{dQ}{dp}=\frac{dQ/dp}{Q/p}$$
    表示价格变动 1% 时需求量变动的百分数（注意常取负号约定，但公式按定义写）。

- **关键定理/公式**：
  1. 利润最大化一阶条件：L'(x)=0 ⇒ MR=MC；二阶条件 L''(x)<0（或 MC 上升快于 MR）。
  2. 需求弹性分类（基于 |E|）：
     - |E|>1：**富有弹性**（降价增产可增收）；
     - |E|=1：单位弹性；
     - |E|<1：**缺乏弹性**（提价可增收）。
  3. 收益对价格的弹性关系：R=p·Q，dR/dp = Q(1+E)（按 E 定义符号）。当 E>-1（即 |E|<1 约定为正弹性）时提价增收益。

- **典型例题**：
  **例1** 设成本 C(x)=100+5x+0.1x²（元），求 x=10 时的边际成本，并解释。
  **解**：MC=C'(x)=5+0.2x，MC(10)=5+2=7（元/件）。含义：在已产 10 件基础上，再增产 1 件总成本约增 7 元。

  **例2** 设需求 Q=100-2p，求 p=30 时的需求弹性并说明属哪类。
  **解**：dQ/dp=-2，Q(30)=100-60=40。E=(30/40)·(-2)=-1.5。|E|=1.5>1，属富有弹性；价格下降 1% 需求量约升 1.5%（按绝对值），应降价促销增收。

- **易错点**：
  1. 边际成本是导数 C'(x)，**不是**平均成本；讲解时强调"近似增量"而非"精确增加"。
  2. 需求弹性公式分母是 dQ/dp，需求常随价升而降（dQ/dp<0），习惯上谈"弹性系数"取绝对值 |E| 分类。
  3. 利润最大需 MR=MC 且验证二阶条件，单令 L'=0 可能得极小值。

## 四、易错点清单

1. **错误做法**：直接套罗尔/拉格朗日不验证条件 → **正确做法**：先逐条核对"闭连续、开可导、端点等值" → **原因**：条件不满足结论可能不成立（如 f(x)=|x| 在 [-1,1] 罗尔失效）。
2. **错误做法**：认为拉格朗日中值定理能求出具体 ξ → **正确做法**：ξ 仅保证存在，通常含于 a,b 间 → **原因**：定理是存在性定理。
3. **错误做法**：lim (x+sin x)/x 误用洛必达得"不存在" → **正确做法**：拆为 1+sin x/x → 1 → **原因**：f'/g' 极限不存在时洛必达失效，原极限仍可存在。
4. **错误做法**：把非未定式当未定式求导 → **正确做法**：先判定型（如 ∞-∞ 先通分）→ **原因**：洛必达仅对 0/0、∞/∞ 有效。
5. **错误做法**：泰勒展开保留阶数不足 → **正确做法**：按目标阶保留并加 o(xⁿ) → **原因**：丢项导致极限/近似错误。
6. **错误做法**：把拉格朗日余项当佩亚诺用（或反之）→ **正确做法**：要误差估用拉格朗日，要极限定性用佩亚诺 → **原因**：二者条件与用途不同。
7. **错误做法**：f''(x₀)=0 即判为拐点 → **正确做法**：验证 x₀ 两侧 f'' 异号 → **原因**：x³ 的驻点 f''=0 但非极值；x⁴ 在 0 处 f''=0 非拐点。
8. **错误做法**：垂直渐近线只看分母为零 → **正确做法**：验证极限确为 ∞ → **原因**：如 (x²-1)/(x-1) 在 1 处可去，非垂直渐近。
9. **错误做法**：边际成本说成"生产第 x 件的精确成本" → **正确做法**：说"再增产 1 件的近似增量" → **原因**：C'(x)≈C(x+1)-C(x) 是近似。
10. **错误做法**：需求弹性不取绝对值就分类 → **正确做法**：按 |E| 分富有/缺乏弹性 → **原因**：dQ/dp 常为负，分类以绝对值论。

## 五、经济应用

（本章经济应用是经管类重点，以下展开讲解用）

**1. 经济中常用函数**
- 成本函数 C(x)=C₀+C₁(x)，C₀ 固定成本，C₁ 可变成本；平均成本 $\bar C(x)=C(x)/x$。
- 收益函数 R(x)=p·x；若需求为 Q(p)，则收益也可表为价格函数 R(p)=p·Q(p)。
- 利润函数 L(x)=R(x)-C(x)。
- 需求函数 Q=Q(p)（价格 p 的递减函数，通常）。

**2. 边际分析（导数读法）**
- 边际成本 MC=C'(x)：产量从 x 增加 1 单位时总成本的近似增量，即 MC(x)≈C(x+1)-C(x)。
- 边际收益 MR=R'(x)：多售 1 单位收益的近似增量。
- 边际利润 ML=L'(x)=MR-MC。
- 讲解要点：边际量是"瞬时变化率"，决策上回答"要不要再产/再卖一件"。
- 例：若 MC(x)<p（售价），增产仍增利，直到 MC=p；若 MC>MR 则应减产。

**3. 弹性分析**
- 定义（点弹性）：
  $$E=\frac{p}{Q}\cdot\frac{dQ}{dp}=\frac{dQ/dp}{Q/p}$$
  表示价格变动 1% 时需求量变动的百分数。由于需求常随价升而降，dQ/dp<0，故 E<0；经济学常谈"弹性系数"即 |E|。
- 经济含义：|E|>1 富有弹性（需求量对价格敏感，降价可大幅增销量、总收益上升）；|E|<1 缺乏弹性（提价能增收益）；|E|=1 单位弹性。
- 收益与弹性关系：R=pQ，对 p 求导 dR/dp=Q+p·dQ/dp=Q(1+dQ/dp·p/Q)=Q(1+E)。若取 |E| 框架（E 记为正值弹性），则 dR/dp=Q(1-|E|)：当 |E|>1 时降价（dp<0）使 dR>0 增收。

**4. 经济学中的最优化**
- 利润最大化一阶条件：L'(x)=0 ⇒ R'(x)=C'(x)，即 **MR=MC**（边际收益=边际成本）。
- 二阶条件：L''(x)<0 即 MR'(x)<MC'(x)，保证是最大而非最小。
- 讲解时强调：企业进行产量决策应在"边际收益等于边际成本"处，而非"平均成本最低"或"产量最大"处。
