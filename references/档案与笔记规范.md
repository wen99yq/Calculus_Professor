# 档案与笔记规范

> 本文件规定 `Calculus_Professor` 落盘的所有文件：目录结构、格式、更新时机。
> **核心约束：一律使用相对路径，档案根目录 = 当前工作目录下的 `微积分学习/`。绝不写入本机绝对路径。**

---

## 一、目录结构

```
微积分学习/
├── 学生档案.md          # 摸底结果、档位、目标、偏好
├── 错题本.md            # 错题 + 错因归类 + 正确思路
├── 学习计划.md          # 薄弱点 → 本周安排 → 阶段自测节点
├── 进度追踪.md          # 各章掌握度评级、练习与自测记录
├── 学习计划_历史/       # 旧版计划归档（重写计划前先归档）
│   └── YYYY-MM-DD.md
├── 笔记/
│   ├── 知识卡片/        # 一卡一知识点（Obsidian 双链）
│   └── 知识地图/        # 各章脉络与公式体系
└── 报告/
    └── YYYY-MM-DD_学习报告.html
```

初始化方式（任选其一）：

```bash
# 方式一：脚本一键生成
python "scripts/create_archive.py" --root "微积分学习"

# 方式二：手动从 templates/ 复制并改名
```

**幂等要求**：初始化脚本**不得覆盖**已存在的档案文件。

### 2.2 `错题本.md`

| 项 | 说明 |
|---|---|
| 写入时机 | 每次批改后**立即追加** |
| 追加规则 | **只追加，不覆盖**；同一题再错则在原条目下追加一行"重犯记录" |

```markdown
## [第4章 · 分部积分] 求 ∫x·eˣ dx
- **日期**：2026-09-17
- **题目**：求 ∫x·eˣ dx
- **我的做法**：取 u=x, dv=eˣdx，写成 x·eˣ − ∫x·eˣ dx
- **错因类别**：计算失误（du 代入错误）
- **正确思路**：u=x ⇒ du=dx；v=eˣ ⇒ ∫u dv = uv − ∫v du = x·eˣ − ∫eˣ dx = x·eˣ − eˣ + C
- **同类提醒**：分部积分时代入 ∫v du 前，务必单独写出 du
- **重犯记录**：2026-09-24 又犯（同类题），已加练 2 题
```

**错因类别固定取值**（便于统计）：`概念不清` / `计算失误` / `思路断点` / `条件误读` / `前置漏洞`。

## 三、知识卡片规范

### 3.1 卡片粒度

**一卡一知识点**——不要一张卡塞一整节。

合格的卡片名示例：`等价无穷小替换`、`洛必达法则的使用条件`、`分部积分法的选取原则`、`定积分换元必换限`
不合格：`第一章总结`、`极限（超长综合）`

### 3.2 卡片模板

```markdown
---
tags:
  - 微积分/第1章/极限
chapter: 第1章 函数与极限
knowledge_point: 等价无穷小替换
mastery: 能独立做
source: 苏德矿《微积分》第三版 上册 第1章
updated: 2026-09-17
---

# 等价无穷小替换

## 一句话
在乘除结构的极限里，可以把无穷小因子换成等价的、更好算的那个。

## 关键内容
当 x→0 时：
- sin x ~ x
- tan x ~ x
- 1 − cos x ~ x²/2
- ln(1+x) ~ x
- eˣ − 1 ~ x
- (1+x)^α − 1 ~ αx
- arcsin x ~ x，arctan x ~ x

## 使用条件
- **仅适用于乘除结构**；加减结构中直接替换会出错（除非用更高阶展开）
- 见 [[洛必达法则的使用条件]]、[[泰勒公式与等价无穷小的关系]]

## 典型例子
求 lim(x→0) (tan x − sin x)/x³ …
（此处写清推导，说明为什么这里**不能**直接把 tan x、sin x 都换成 x）

## 易错点
- 在加减法里直接替换 → 结果为 0，实际答案 1/2
- 见 [[等价无穷小替换的三个常见错误]]

## 关联
- 前置：[[无穷小的阶]]
- 后续：[[洛必达法则的使用条件]]、[[泰勒公式]]
```

### 3.3 双链纪律

1. 只对**已存在或本次一并创建**的卡片建 `[[双链]]`。
2. 暂时没有对应卡片的知识点，写成 `待建卡片：xxx`，**不要**写成双链（避免死链堆积）。
3. 卡片被创建后，回头把其他卡片里的 `待建卡片：xxx` 改为 `[[xxx]]`。
4. 卡片名与文件名一致（文件名去掉 `.md`），便于 Obsidian 解析。

### 3.4 文件名安全

避免使用：`\ / : * ? " < > |` 以及首尾空格、以 `.` 开头。
`ε δ ξ` 等希腊字母可以安全使用；`∫ ∑ √` 建议改写成文字（如 `定积分`、`求和符号`）以保证跨系统稳定。

## 五、写入与读取纪律

### 读取（每次相关操作前）

| 场景 | 必读 |
|---|---|
| 出题 | `学生档案.md`、`错题本.md`、`进度追踪.md` |
| 批改 | `错题本.md`（查是否重犯） |
| 生成计划 | `学生档案.md`、`错题本.md`、`进度追踪.md` |
| 生成报告 | 以上全部 |

### 写入

| 时机 | 目标文件 | 方式 |
|---|---|---|
| 批改后 | `错题本.md` | 追加 |
| 练习后 | `进度追踪.md` | 追加/更新表格行 |
| 章末自测后 | `进度追踪.md` | 更新掌握度 |
| 档位变更 | `学生档案.md` | 更新（先获同意） |
| 生成计划 | `学习计划.md` | 重写（旧版先归档） |
| 讲解后被要求整理 | `笔记/知识卡片/` | 新建或更新 |

- **先读后写**：更新表格类文件前先读当前内容，避免覆盖学生已有记录。
- **不删内容**：除 `学习计划.md`（旧版归档后可重写）外，一律追加，不删除历史。
- **报错要直说**：写盘失败（权限/路径）时如实告知，不要把失败说成成功。

## 六、Obsidian 落位

档案目录与 Obsidian vault 的关系见 `Obsidian联动与Vault探测.md`：

- **探测到 vault** → 知识卡片与知识地图写入 `<vault>/微积分/` 下，按章分文件夹
- **未探测到** → 留在 `微积分学习/笔记/`，并提示学生可手动指定 vault
- 两种情形下**卡片内容与文件名完全一致**，便于日后整体搬迁
