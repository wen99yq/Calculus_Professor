## 一、逐节知识速查
### § 函数
- **核心定义**：设 x 和 y 是两个变量，D 是一个给定的数集。若对于每个数 x∈D，按照某一对应法则 f，都有唯一确定的实数 y 与之对应，则称 y 是 x 的函数，记作 y = f(x)，x 称为自变量，D 称为定义域。
- **关键定理/公式**：
  1. 函数相等的充要条件：定义域相同且对应法则相同。
  2. 有界性：存在 M>0，使 |f(x)|≤M 对定义域内一切 x 成立，则 f 有界。
  3. 单调性：x₁<x₂ ⇒ f(x₁)≤f(x₂) 为单调增；反之为单调减。
  4. 奇偶性：f(-x)=f(x) 为偶函数；f(-x)=-f(x) 为奇函数。奇（偶）函数定义域必关于原点对称。
  5. 周期性：存在 T≠0，使 f(x+T)=f(x) 对定义域内一切 x 成立，最小正周期称为周期。
- **典型例题**：
  **例1** 判断函数 f(x) = ln(x+√(x²+1)) 的奇偶性。
  **解** 定义域为 ℝ（因 x+√(x²+1)>0 恒成立）。计算
  f(-x) = ln(-x+√(x²+1)) = ln( (√(x²+1)-x)(√(x²+1)+x)/(√(x²+1)+x) )
  = ln( 1/(x+√(x²+1)) ) = -ln(x+√(x²+1)) = -f(x)。
  故 f 为奇函数。
- **易错点**：
  1. 误用 f(a+x)=f(a-x) 当作周期函数；这仅表示关于直线 x=a 对称，非周期。
  2. 奇函数在 x=0 有定义时必有 f(0)=0，但 f(0)=0 不能反推奇函数。
  3. 复合函数定义域需由内层函数的值域与外层定义域共同决定。

### § 数列极限
- **核心定义**：设 {xₙ} 为一数列，若存在常数 a，对任意 ε>0，存在正整数 N，当 n>N 时恒有 |xₙ-a|<ε，则称数列 {xₙ} 收敛于 a，记作 $\lim\limits_{n\to\infty}x_n=a$。
- **关键定理/公式**：
  1. 唯一性：收敛数列极限唯一。
  2. 有界性：收敛数列必有界（逆否：无界数列必发散）。
  3. 保号性：若 $\lim x_n=a>0$，则 ∃N，当 n>N 时 xₙ>0；若从某项起 xₙ≥0 且收敛，则极限 ≥0。
  4. 夹逼准则：yₙ≤xₙ≤zₙ 且 $\lim y_n=\lim z_n=a$ ⇒ $\lim x_n=a$。
  5. 单调有界准则：单调增且有上界（或单调减且有下界）的数列必收敛。
- **典型例题**：
  **例1** 证明 $\lim\limits_{n\to\infty}\frac{1}{n}=0$。
  **解** 任给 ε>0，要使 |1/n - 0| = 1/n < ε，只需 n > 1/ε。取 N = [1/ε]（取整），则当 n>N 时 1/n < ε 成立。证毕。
- **易错点**：
  1. 有界是收敛的必要非充分条件（如 (-1)ⁿ 有界但发散）。
  2. 保号性不可取严格不等号：由 xₙ>0 收敛只能得极限 ≥0，不能得 >0。
  3. 单调有界准则只保证存在极限，不能直接给出极限值，常需另求（如设极限为 l 列方程）。

### § 函数极限
- **核心定义**：
  - $x\to x_0$：$\lim\limits_{x\to x_0}f(x)=A$ ⇔ ∀ε>0，∃δ>0，当 0<|x-x₀|<δ 时 |f(x)-A|<ε。
  - $x\to\infty$：$\lim\limits_{x\to\infty}f(x)=A$ ⇔ ∀ε>0，∃X>0，当 |x|>X 时 |f(x)-A|<ε。
  - 左右极限：$f(x_0^-)=\lim\limits_{x\to x_0^-}f(x)$，$f(x_0^+)=\lim\limits_{x\to x_0^+}f(x)$。
- **关键定理/公式**：
  1. $\lim\limits_{x\to x_0}f(x)=A$ ⇔ $f(x_0^-)=f(x_0^+)=A$。
  2. 两个重要极限：$\lim\limits_{x\to 0}\frac{\sin x}{x}=1$；$\lim\limits_{x\to\infty}(1+\frac{1}{x})^x=e$（等价形式 $\lim\limits_{x\to 0}(1+x)^{1/x}=e$）。
  3. 无穷小比较：若 $\lim\alpha=\lim\beta=0$，则
     - $\lim\frac{\alpha}{\beta}=0$：α 是比 β 高阶的无穷小（α=o(β)）；
     - $\lim\frac{\alpha}{\beta}=c\neq0$：同阶；c=1 时等价 α~β；
     - $\lim\frac{\alpha}{\beta}=\infty$：α 是比 β 低阶的无穷小。
  4. 等价无穷小替换（x→0）：sin x~x，tan x~x，arcsin x~x，arctan x~x，1-cos x~x²/2，ln(1+x)~x，eˣ-1~x，(1+x)^a-1~ax，aˣ-1~x ln a。
- **典型例题**：
  **例1** 求 $\lim\limits_{x\to0}\frac{\tan x-\sin x}{x^3}$。
  **解** $\tan x-\sin x = \sin x(\frac{1}{\cos x}-1) = \sin x\cdot\frac{1-\cos x}{\cos x}$。
  当 x→0，$\sin x\sim x$，$1-\cos x\sim x^2/2$，$\cos x\to1$，故原式 $\sim x\cdot(x^2/2)/1 / x^3 = 1/2$。极限为 1/2。
  **例2** 求 $\lim\limits_{x\to\infty}(1+\frac{2}{x})^x$。
  **解** 令 t=x/2，则 x=2t，原式 = $\lim\limits_{t\to\infty}(1+\frac{1}{t})^{2t} = \left[\lim\limits_{t\to\infty}(1+\frac{1}{t})^t\right]^2 = e^2$。（亦可用对数法：令 y=(1+2/x)^x，ln y = x ln(1+2/x) ~ x·(2/x) = 2，故 y→e²。）
- **易错点**：
  1. 等价无穷小替换只能在乘除法中使用，加减法中替换可能出错（如上例须先因式分解）。
  2. 左、右极限不相等时极限不存在，但分别可求（分段函数考点）。
  3. 无穷大量不是数，不能当普通数运算；∞-∞、0·∞ 为未定式。

### § 函数的连续性
- **核心定义**：若 $\lim\limits_{x\to x_0}f(x)=f(x_0)$，则称 f 在 x₀ 连续。即 Δy = f(x₀+Δx)-f(x₀) → 0（Δx→0）。
- **关键定理/公式**：
  1. 间断点分类：
     - 第一类（左右极限都存在）：可去间断点（左右极限相等但不等函数值或无定义）、跳跃间断点（左右极限不等）。
     - 第二类（至少一个单侧极限不存在）：无穷间断点、振荡间断点。
  2. 连续函数的四则运算、复合、反函数（单调连续函数的反函数连续）均连续。
  3. 一切初等函数在其定义区间上连续。
  4. 闭区间上连续函数性质：有界性定理、最大值最小值定理、介值定理、零点定理（若 f(a)f(b)<0，则 ∃ξ∈(a,b) 使 f(ξ)=0）。
- **典型例题**：
  **例1** 设 f(x)={x², x≤1; ax+b, x>1}，问 a,b 取何值时 f 在 x=1 连续。
  **解** f(1)=1；左极限 $\lim\limits_{x\to1^-}x^2=1$；右极限 $\lim\limits_{x\to1^+}(ax+b)=a+b$。连续须 a+b=1。故取满足 a+b=1 的任意 a,b 即可。
  **例2** 讨论 f(x)=sin(1/x) 在 x=0 的间断类型。
  **解** x=0 处无定义；且 x→0 时 1/x→∞，sin(1/x) 在 -1 与 1 之间无限振荡，左右极限均不存在。故 x=0 为第二类间断点中的振荡间断点。
- **易错点**：
  1. 初等函数"在定义区间"而非"定义域"连续（定义域可能含孤立点导致不连续）。
  2. 可去间断点可通过补充/修改一点定义变为连续。
  3. 零点定理只保证存在性，不保证唯一性，且要求 f 在 [a,b] 连续及 f(a)f(b)<0。

## 二、本章公式总表
| 公式 | 适用条件 | 常见变形 / 记忆提示 |
|---|---|---|
| $\lim\limits_{n\to\infty}x_n=a$（ε-N） | 任给 ε>0，∃N，n>N 时 |xₙ-a|<ε | N 依赖 ε，非唯一 |
| $\lim\limits_{x\to x_0}f(x)=A$（ε-δ） | 0<\|x-x₀\|<δ ⇒ |f-A|<ε | 极限与 f(x₀) 取值无关 |
| 左右极限相等判定 | $f(x_0^-)=f(x_0^+)$ | 分段函数、绝对值函数必查 |
| $\lim\limits_{x\to0}\frac{\sin x}{x}=1$ | x→0 | 凑角：arcsin、tan 同类 |
| $\lim\limits_{x\to\infty}(1+\frac{1}{x})^x=e$ | x→∞（或 1^∞ 型） | 牢记 $\lim(1+x)^{1/x}=e$ |
| 等价无穷小 sin x~x | x→0 | 乘除替换用 |
| 等价无穷小 1-cos x~x²/2 | x→0 | 别误用 x |
| 等价无穷小 ln(1+x)~x | x→0 | 别漏括号 |
| 等价无穷小 eˣ-1~x | x→0 | aˣ-1~x ln a |
| 等价无穷小 (1+x)^a-1~ax | x→0 | 二项式近似 |
| 连续定义 $\lim_{x\to x_0}f(x)=f(x_0)$ | 点连续 | 含极限存在且等于函数值 |
| 零点定理 | f∈C[a,b], f(a)f(b)<0 | ∃ξ∈(a,b), f(ξ)=0 |
| 介值定理 | f∈C[a,b]，μ 介于 f(a),f(b) | ∃ξ, f(ξ)=μ |
| 有界函数×无穷小→无穷小 | 乘积极限 | 若 |g|≤M 且 α→0，则 gα→0 |
| $\lim\limits_{x\to\infty}1/x^k=0$ | k>0, x→∞ | 指数越大趋于0越快 |
| $\lim\limits_{x\to0^+}1/x^k=\infty$ | k>0 | 注意趋于0的方向 |
| 局部保号性 | f(x)>0 在某邻域内 ⇒ 极限≥0 | 与保号性互为补充 |
| 复合极限 $\lim f(g(x))=f(\lim g)$ | 外层 f 在极限点连续 | 先求内层极限再代入 |

## 三、常见题型与解题套路
| 题型 | 识别特征 | 首选方法 | 备选方法 | 陷阱 |
|---|---|---|---|---|
| 求分段函数极限 | 含绝对值/分段 | 分别求左右极限 | 去绝对值讨论 | 漏查单侧 |
| 利用两个重要极限 | sin□/□ 或 (1+□)^(1/□) | 凑成标准型 | 取对数 | 角度不趋于0 |
| 等价无穷小化简 | 乘积/商含 x→0 小量 | 替换后约分 | 泰勒展开 | 加减中滥用替换 |
| 证明数列极限 | 给 ε 证存在 N | 由 |xₙ-a|<ε 反解 N | 单调有界准则 | N 须为正整数 |
| 单调有界准则证收敛 | 递推数列 | 先证单调再证有界 | 压缩映射 | 有界≠收敛 |
| 间断点分类 | 分段/分母为零点 | 算左右极限判断 | 画图 | 混淆第一/二类 |
| 零点/介值定理应用 | 方程根存在性 | 验证连续与异号 | 构造辅助函数 | 区间端点不连续 |
| 函数特性判定 | 判断奇偶/周期 | 代入 f(-x) | 画图 | 定义域不对称 |
| 复合函数定义域 | 含 √(·)、ln(·) | 层层限制求交集 | 数集运算 | 漏内层值域约束 |
| 连续复利极限 | 求 (1+r/n)^(nt) 当 n→∞ | 化为 e^{rt} | 取对数 | 混淆 n 与 t 的极限 |
| 无穷小阶比较 | 求 lim α/β | 化为等价量或比值 | 泰勒展开 | 忽略高阶项致错 |
| 分段点连续性 | 分界点处 | 极限=函数值 | 左右极限 | 漏查函数值 |

## 四、易错点清单
1. **错误做法**：认为有界数列必收敛 → **正确做法**：有界只是收敛的必要条件，如 (-1)ⁿ → **原因**：还需附加单调等条件。
2. **错误做法**：由 xₙ>0 收敛推出极限 >0 → **正确做法**：只能得极限 ≥0 → **原因**：保号性取不到严格不等号。
3. **错误做法**：在加减式中直接做等价无穷小替换 → **正确做法**：先因式分解或通分，仅乘除替换 → **原因**：替换会丢失高阶差项（如 tanx-sinx）。
4. **错误做法**：把 ∞ 当数参与四则运算 → **正确做法**：识别未定式另求 → **原因**：∞ 是变化趋势非实数。
5. **错误做法**：极限存在即认为函数在该点连续 → **正确做法**：还需极限值等于函数值 → **原因**：可去间断点极限存在但不连续。
6. **错误做法**：说初等函数在其定义域连续 → **正确做法**：应在定义区间连续 → **原因**：定义域可含孤立点。
7. **错误做法**：左右极限存在不等就称无穷间断 → **正确做法**：属第一类跳跃间断点 → **原因**：第二类才有一侧不存在。
8. **错误做法**：零点定理得唯一根 → **正确做法**：仅得存在性 → **原因**：未证单调性不能保证唯一。
9. **错误做法**：f(x)=f(-x) 即证偶函数不看定义域 → **正确做法**：先确认定义域关于原点对称 → **原因**：奇偶性前提。
10. **错误做法**：极限不存在就断言趋于无穷 → **正确做法**：可能振荡发散（如 x→0 时 sin(1/x)）→ **原因**：发散含无穷与振荡两类。
11. **错误做法**：夹逼只证一侧 yₙ≤xₙ → **正确做法**：还需 zₙ≥xₙ 且两端同极限 → **原因**：单向夹不住。
12. **错误做法**：复合极限直接整体代入 → **正确做法**：需外层在该点连续 → **原因**：连续才能交换极限与函数。

## 五、经济应用
- **复利模型**：$A=P(1+r/n)^{nt}$，P 本金，r 年利率，n 年复利次数，t 年。
- **连续复利**：令 n→∞，$A=\lim\limits_{n\to\infty}P(1+r/n)^{nt}=Pe^{rt}$。此处直接用到本章第二个重要极限。
- **流行度/增长函数**：指数增长 $N(t)=N_0 e^{kt}$ 源于极限 $\lim(1+k/n)^n=e$。
- 可关联的经济背景：现值贴现、人口/资本存量模型均建立在连续复利极限思想之上。
- 补充：增长率 k 的连续模型 dN/dt=kN 的解正是 N(t)=N₀e^{kt}，与第二个重要极限同源。
